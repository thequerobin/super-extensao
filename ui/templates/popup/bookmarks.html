Importar dos favoritos

 Importe os domínios de uma pasta para a lista de exceções escolhida abaixo. Os favoritos não serão modificados. Lista de destino O acesso aos favoritos também permite sincronizar pastas no painel de sincronização. A importação é uma cópia: mudanças futuras na pasta não atualizam as exceções. Links HTTP/HTTPS são aceitos e duplicados são ignorados.
